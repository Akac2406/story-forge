# Story Forge

Personal interactive-story app (single-file PWA).

- `site/` — the app Netlify publishes (`index.html`, `memory-engine.js`, `sw.js`, the memory trial page).
- `tests/` — automated tests (`python tests/run_all.py`).
- `docs/` — changelogs, trial reports and design notes.

API keys and stories are never stored here; they live only in each browser's own storage.
